<h1 align="center">🌍 Travel App (React Native)</h1>
<p align="center">A starter template for a travel app with authentication and navigation system</p>

---

## 🎯 Proje Hakkında

Bu proje, React Native ile oluşturulmuş bir **seyahat uygulaması başlangıç şablonudur**.  
Proje içerisinde:

- Giriş ve kayıt (auth) sayfaları  
- Drawer menü (yan menü)  
- Tab tabanlı navigasyon  
- Temel sayfa yapıları (örneğin: Home, Profile, Explore vb.)  

gibi birçok temel yapı hazır olarak sunulmaktadır. Uygulama temel alınarak genişletilebilir yapıda tasarlanmıştır.

---

## 🛠️ Kullanılan Teknolojiler

- React Native  
- React Navigation (Drawer & Tab)  
- JavaScript (ES6+)  
- Expo
